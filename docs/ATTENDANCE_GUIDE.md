# 勤怠・出面機能の使い方

日報から勤怠(給与計算の根拠)と出面(元請請求・現場原価の根拠)を自動で作る機能です。

## 従業員(一般社員)向け

### 日報に自分の勤務を記録する

1. いつも通り日報を作成・保存する
2. 日報の詳細画面の「作業員(勤怠・出面)」欄で、自分(または一緒に働いた人)を追加する
   - 自社の従業員なら、プルダウンから選ぶ
   - 協力会社・外注・その名前がまだ登録されていない人は、直接名前を入力する
3. 開始時間・終了時間・休憩・人工数・作業内容を入れて「+ 作業員を追加」を押す
4. これで自動的に、追加した人の勤怠・出面が作られる

### 自分の勤怠を確認・提出する

1. メニューの「自分の勤怠」を開く
2. 月ごとに、出勤・退勤・休憩・実働時間・残業時間が確認できる
3. 内容が違う場合は、その場で直せる(下書き・差し戻し中の分だけ)
4. 内容に間違いがなければ「この内容で提出する」を押す
5. 管理者が承認すると、以後は自分で直せなくなる(差し戻された場合は再度直して提出できる)

## 管理者向け

### 現場責任者を設定する

1. [設定]→[チーム]で、担当してもらいたい人の権限を「現場責任者」にする
2. 各案件の詳細画面の「現場責任者」欄で、その人がどの現場を担当するか選ぶ
3. 現場責任者は、担当している現場の日報・出面だけを見られ、一次承認ができる
   (単価の設定・締め処理・締め解除は引き続き管理者のみ)

### 利用者と従業員を紐付ける

勤怠を「誰のものか」正しく判定するため、ログインアカウント(利用者)と従業員マスタを
紐付ける必要があります。

1. [従業員]の詳細画面を開く(管理者のみ表示される欄があります)
2. 「ログイン利用者との関連付け」欄で、対応する利用者を選んで「関連付ける」を押す

これをしていない利用者は、「自分の勤怠」画面が使えません(誰の勤怠か特定できないため)。

### 勤怠を承認する

1. メニューの「勤怠管理」を開く
2. 提出済みの勤怠にチェックを入れて「一括承認」、または個別に「差し戻す」
3. 差し戻す場合は理由を入力する(本人に表示されます)
4. その月の承認済み分がすべて確定したら「まとめて締める」を押す
   - 締めた後は通常編集できません。修正が必要な場合は「締め解除」(理由の入力が必須)

### 出面を確認・承認する

1. メニューの「出面・常用集計」を開く
2. 現場別・元請別・従業員別・日別・職種別で人工数や金額を確認できる
3. 提出済みの出面は「確認して承認」から、日報の内容(写真・作業内容・車両重機等)と
   あわせて確認したうえで承認・差し戻しができる
4. 人工単価は出面一覧からその場で入力できる(単価・金額は管理者だけが見られます)

### Excelで出力する

- 「勤怠管理」画面の「勤怠表をExcelでダウンロード」
- 「出面・常用集計」画面の「出面集計表をExcelでダウンロード」

対象年月で絞り込んだ内容がそのままExcelファイルになります(ファイル名に会社名・
帳票名・対象年月が入ります)。

## 注意点

- 日報を後から編集・削除しても、すでに承認・締め済みの勤怠・出面は自動では変わりません
  (給与・請求が確定した後に勝手に数字が動かないようにするためです)
- 従業員には、単価・金額は一切表示されません(管理者・現場責任者のみ)
