# AI開発の運用手順

## 1. 依頼

ChatGPTで要望を整理し、`docs/ai-tasks`へ1件ずつ記録する。

## 2. 実装

Claude Codeが専用の作業用ブランチで実装する。

ブランチ名の例：`feature/attendance-from-daily-report`

## 3. 検査

Codexが次を確認する。

- 指示どおり動くか
- 他の機能を壊していないか
- 社員間の同期が正しいか
- 他社データが見えないか
- スマホでも操作できるか

## 4. 承認

杉本さんがテスト環境で確認する。

## 5. 公開

承認済みの変更だけを本番へ反映し、公開日時と結果を作業指示へ残す。
